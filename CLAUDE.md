# Project instructions

## Process
- This project uses BMAD-style docs (AGENTS.md, NEGOTIATION_SPEC.md) as its
  PRD/spec — treat them as already-done planning.
- Do NOT run the full BMAD pipeline (bmad-prd, bmad-spec, bmad-architecture,
  bmad-create-epics-and-stories, bmad-sprint-planning) unless explicitly asked.
- Always read AGENTS.md and NEGOTIATION_SPEC.md before starting any task in
  this repo.
- Build in milestone-sized increments and stop for review after each one,
  don't chain multiple milestones together unprompted.
